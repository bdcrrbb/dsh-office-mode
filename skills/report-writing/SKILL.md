# 写作方法论与结构决策

本 skill 跨 docx/pptx/xlsx 复用，管"写什么、什么结构"，不管"怎么生成"（那是格式 skills 的职责）。

## 结构选择表

| 场景 | 结构 | 适用 |
|---|---|---|
| 深度调研报告 | **金字塔原理** | 结论先行，分层论证，数据支撑，适合 10 页 + 长报告 |
| 汇报叙事 | **SCQA** | Situation-Complication-Question-Answer，适合背景→问题→方案的叙事流 |
| 一页纸简报 | **BLUF** | Bottom Line Up Front，结论→关键数据→行动建议，≤1 页 |
| 党政机关公文 | **GB/T 9704** | 严格格式规范，见下文参数表 |

## 公文版式细则（GB/T 9704-2012 补充，2026-09-02）

| 元素 | 规范 |
|---|---|
| 正文段落 | 每自然段首行缩进 2 字，回行顶格 |
| 结构层次标题（一、/(一)/1./(1)） | **与正文一致，首行缩进 2 字**（非顶格——真实红头文件实践；勿用企业文书的顶格流派） |

## 大纲先行流程（必须执行）

1. **确认需求**：受众、篇幅、用途、风格（用户已给的不重复问）
2. **产出大纲**：按选择的结构（金字塔/SCQA/BLUF/公文）列出大纲
3. **等用户确认**：大纲确认后再写正文
4. **写正文**：按大纲逐节展开
5. **自检**：结构完整性、字体规范、引用标注

## 产出物落盘规范

产物落盘位置(按序判定):
1. **项目已有安排 → 跟随项目**:用户指定过目录、项目内已有同类产物目录(如 docs/、deck/、报告归档处)、项目级 AGENTS.md/README 有归置说明、或 OpenViking 记忆记录过该项目产出位置——产物放项目安排的位置,文件命名也从项目惯例。
2. **项目无安排 → 后备默认**:当前工作目录下 `./output/YYYY-MM-DD-<slug>/`(相对路径)。
3. **禁止**:~/office 或任何用户主目录固定路径;禁止在无安排时自创平行目录散落文件。拿不准就问用户一句"放哪"。
